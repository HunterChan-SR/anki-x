# 0.1.1：学习卡停留后的评分修复

用户症状：employer 的答案页停留约 48 秒，评分时报 `Prediction/conversion token is stale.`。

根因：AnkiConnect 的 scheduling token 包含完整预测状态；日内学习卡的 `current.normal.learning.elapsedSecs` 随时间增长。卡片正文与数据库记录没有改变，保存于显示卡片时的 token 也会因为跨秒而失效。原客户端没有在评分时更新预测，且错误处理只检查几个数字错误码，直接展示了英文 conflict。

复现使用 Anki 26.9.3 和官方 AnkiConnect 源码的真实服务，在独立临时 collection 中创建学习卡。停留 1.2 秒后调用原客户端评分，两次均报同样错误。对比确认存储卡片完全相同，仅预测的 elapsedSecs 从未设置变为 2。

修复：

- 在按评分键时获取新 token，随后检查卡片与词条内容仍与屏幕展示一致。
- 只对明确拒绝于写入前的 typed conflict 有限重试，每次重新核对卡片；不重试网络中断或未知结果。
- 已在别处评分或修改的卡片不会被自动再评分。
- 使用结构化错误类型，给出中文处理提示。

验证：17 项单元测试通过；原来的隔离复现已通过；强制提交时再跨过一秒也通过。两种隔离回归均断言最终只新增一次评分。`anki-x --version` 返回 `0.1.1`。

本轮测试没有连接或修改用户正在学习的 Anki collection。正在运行的旧终端进程需退出后重新启动，才能加载新代码。
