# Changelog

## 1.0.0rc1

- Cross-platform Textual interface for macOS, Windows and Linux.
- First-run Anki detection, official download, add-on setup and port discovery.
- User-directory configuration with backups and migration from 0.2.x.
- Bundled audio decoder/player; no external audio-player dependency.
- Original sample cards and pronunciations; existing deck and package import entry points.
- Connection recovery, account selection, settings, help and private diagnostic export.
- Self-contained platform builds, installer, versioned update and rollback foundations.

This is a release candidate. Release validation and signing status are reported separately; a successful local build does not certify every platform.

## 0.2.0

- Hierarchical deck home screen, back navigation and saved screen restoration.

## 0.1.x

- Native Anki scheduling, audio, undo, automatic pronunciation and title visibility.
- Learning-card stale prediction fix and rename to anki-x.
